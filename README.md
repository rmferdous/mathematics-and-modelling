# Model Lab for Mathematics and Modelling

Learning maths through building models: a self-directed curriculum from A-level
foundations to complexity economics, one animated agent-based model per phase.

Each build pairs a hand derivation with a simulation, and checks whether
the analytical answer matches what the model does.
